pingrail is licensed under the Apache License, Version 2.0 (see LICENSE).

brackets is the one pingrail uses.

Also included
-------------
  The Rust standard library — MIT OR Apache-2.0 (used under MIT).
      https://github.com/rust-lang/rust
  Windows builds: the mingw-w64 runtime (CRT start-up code and winpthreads,
      MIT/ZPL/public domain) and libgcc (GPL-3.0 with the GCC Runtime Library
      Exception). https://www.mingw-w64.org/
  Linux builds link the system C library (glibc, LGPL-2.1) dynamically.
  SQLite (bundled through rusqlite) — public domain. https://sqlite.org/copyright.html
  OpenSSL 3.6.3, compiled in through openssl-src for passkeys (WebAuthn):
      Apache-2.0, text below. https://www.openssl.org/
  Mona Sans and Martian Mono, the web UI's fonts, are built into the program
      (the Latin files exactly as Google Fonts publishes them, unmodified):
      SIL Open Font License 1.1, texts below.
      https://github.com/github/mona-sans  https://github.com/evilmartians/mono
  DejaVu fonts, used for reports, ship as separate files (fonts/), not part of
      the program: Bitstream Vera / DejaVu licence, see fonts/LICENSE-DejaVu.txt.
