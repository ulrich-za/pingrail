      Set up a phone

      Point the phone’s camera at each code in turn.

      1. 1Trust this server

        The phone warns the connection isn’t private: that’s expected until this step is done. Continue, download the certificate and check its fingerprint matches.

        SHA-256

        iPhone and iPad

        Allow the download, then open Settings › General › VPN & Device Management to install it. Then turn it on in Settings › General › About › Certificate Trust Settings.

        Android

        Open Settings › Security › More security settings › Encryption & credentials › Install a certificate › CA certificate, and choose the downloaded file. (Menu names vary a little by phone.)

      2. 2Open pingrail

        Sign in, then add a passkey from the menu (Passkeys) so the phone can sign in with its screen lock.
